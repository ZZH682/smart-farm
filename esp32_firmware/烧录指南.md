# 智慧农业 ESP32-C3 节点烧录指南（最新版）

> 本指南对应 **ESP32-C3**（RISC-V 架构）固件，与 Arduino IDE 中 `ESP32C3 Dev Module` 板型配套。
> ⚠️ 旧版指南的引脚（GPIO14/27/26/25 继电器、GPIO5=DS18B20）是针对 ESP32-WROOM-32 的，**不要照旧版接线**。

## 二、接线图（ESP32-C3 版）

### 默认引脚分配

| ESP32-C3 引脚 | 连接到 | 说明 |
|---|---|---|
| GPIO5 | 继电器1 IN | 风扇（已接） |
| GPIO18 | 继电器2 IN | 水泵（预留） |
| GPIO19 | 继电器3 IN | 补光灯（预留） |
| GPIO20 | 继电器4 IN | 通风（预留） |
| GPIO4 | DHT11 DATA | 空气温湿度（未接） |
| **GPIO3** | **YL-69 AO** | **土壤湿度模拟输出（ADC1，WiFi 下稳定）** |
| GPIO10 | DS18B20 DATA | 土壤温度（可选，需 4.7kΩ 上拉） |
| 3V3 | 传感器 VCC | 传感器供电 |
| GND | 所有 GND | 共地 |
| 5V (VIN) | 继电器模块 VCC | 继电器供电（负载大时外接 5V） |

### 接线示意图

```
ESP32-C3              DHT11
--------              -----
3V3  ---------------> VCC
GND  ---------------> GND
GPIO4 ---------------> DATA   (模块自带上拉则无需外接)

ESP32-C3              YL-69 土壤湿度模块
--------              ------------------
3V3  ---------------> VCC
GND  ---------------> GND
GPIO3 ---------------> AO    ← 模拟输出（接 DO 只输出"干/湿"两态，不推荐）
(DO 不接)

ESP32-C3              DS18B20 防水探头（可选，需另购）
--------              -------------------
3V3  ---------------> VCC (红线)
GND  ---------------> GND (黑线)
GPIO10 -------------> DATA (黄线)
(数据线接 4.7kΩ 上拉到 3.3V)

ESP32-C3              4路继电器模块
--------              -----------
GPIO5 ---------------> IN1 (风扇)
GPIO18 --------------> IN2 (水泵)
GPIO19 --------------> IN3 (补光灯)
GPIO20 --------------> IN4 (通风)
5V    ---------------> VCC
GND   ---------------> GND
```

### ⚠️ 引脚红线（ESP32-C3 专用）

1. **不要用 GPIO6-10 接模拟传感器（ADC2）**：ESP32-C3 的 ADC2（GPIO5-10）在 **WiFi 开启时会读取失败**！YL-69 必须接 **GPIO3（ADC1）**。
2. **不要用 GPIO20/21 接外设**：GPIO20=UART0_RX、GPIO21=UART0_TX，串口监视器依赖它们。DS18B20 用 **GPIO10**。
3. **GPIO12-17 是 SPI Flash，不可用**；GPIO11 是 strapping 引脚，避开。
4. 继电器模块 GND 必须与 ESP32 共地；继电器 VCC 接 5V（不是 3.3V）。
5. 控制 220V 设备时务必断电接线，火线接 COM，设备线接 NO。

## 四、修改固件配置（config_secret.h，勿改 .ino）

> **v2.1 起**：WiFi 密码 / MQTT 地址等私密配置已从 `.ino` 抽到同目录的 **`config_secret.h`**，
> 该文件已被 `.gitignore` 排除。**答辩、分享、开源前务必替换里面的 WiFi 密码**，避免隐私泄露。
> 编辑 `config_secret.h` 后保存，再编译烧录即可（Arduino 会自动包含同目录头文件）。

### 1. WiFi 配置（config_secret.h）
```cpp
#define WIFI_SSID       "iQOO Z11 Turbo"
#define WIFI_PASSWORD   "6190503a"
```
改成你的 WiFi 名称密码（手机热点名也是 WiFi）。

### 2. MQTT Broker 配置（最重要！）
```cpp
#define MQTT_BROKER     "172.16.132.211"
```
改成**运行智慧农业系统的电脑的局域网 IP**：
- 电脑 `ipconfig` 看 IPv4 地址
- ESP32 和电脑必须连**同一个 WiFi/热点**
- 电脑 IP 变了就要改这里并**重新烧录**

### 3. MQTT 认证（可选，建议开启）
- 服务端 `config.py` 配置 `MQTT_USERNAME` / `MQTT_PASSWORD` 并启用 Mosquitto 认证后，
- 在 `config_secret.h` 中同步填写 `MQTT_USERNAME` / `MQTT_PASSWORD`，重新烧录即可。

### 4. 传感器安装开关（.ino 中，重要！）
```cpp
#define DHT11_INSTALLED     0    // 接了 DHT11 改成 1
#define YL69_INSTALLED      0    // YL-69 到货接线后改成 1
```
**只有接了传感器才设 1**！悬空引脚会读出假数据并发布，污染整个系统。

### 5. 继电器触发电平（.ino 中）
```cpp
#define RELAY_ACTIVE_LEVEL  LOW
```
大多数模块低电平触发保持 LOW；高电平触发改 HIGH。

## 五、烧录步骤

### 方式A：USB 数据线（USB 口正常时）

1. 用**数据线**连接 ESP32-C3 到电脑
2. 工具 → 端口 → 选 COM 口
3. 点「上传」（Ctrl+U）
4. 成功标志：`Hard resetting via RTS pin...`

### 方式B：CH340 TTL 串口烧录（推荐，绕过损坏的 USB）

你的板子 USB 口已出现"代码43/设备描述符失败"（USB 硬件损坏），**串口烧录是稳定通道**：

1. 购买 CH340 模块（几块钱），接线：
   - CH340 `TX` → ESP32 `GPIO20`（UART0_RX）
   - CH340 `RX` → ESP32 `GPIO21`（UART0_TX）
   - CH340 `GND` → ESP32 `GND`
   - **不要接 VCC！ESP32 用充电器/充电宝独立供电**
2. 电脑装 CH340 驱动（CH341SER）
3. 工具 → 端口 → 选 CH340 的 COM 口
4. 按住 ESP32 的 `BOOT` 键不放 → 点上传 → 看到「上传中...」再松手
5. 成功标志：`Hard resetting via RTS pin...`

> ⚠️ 记住：ESP32 平时运行用**充电器独立供电**（USB 数据口坏了不影响供电），只有烧录时才接电脑。

### 常见上传失败处理

| 报错 | 处理 |
|---|---|
| `Could not open COM3, the port doesn't exist` | USB 口又抽风了，换方式B（CH340）烧录 |
| `This chip is ESP32-C3 not ESP32` | 开发板选错了，选 `ESP32C3 Dev Module` |
| `riscv32-esp-elf-g++ not found` | ESP32 硬件包损坏，重新安装 `ESP32 by Espressif` |
| `Timed out waiting for packet header` | 按住 BOOT 再点上传 |
| 代码 43 / 设备描述符失败 | USB 硬件损坏，走方式B |

## 七、系统端"模拟器让位"机制（已内置）

系统已升级：**ESP32 在发真实数据的参数，模拟器自动停发；ESP32 没覆盖的参数，模拟器补位**。
- 接上 YL-69 重烧后 → 土壤湿度变真实数据，模拟器自动让位
- 没接的传感器 → 模拟器继续提供演示数据，Web 不空窗
- 无需手动切换

## 八、常见问题排查

| 问题 | 原因/解决 |
|---|---|
| ESP32 连不上 WiFi | 密码错误/不是2.4G/热点开了设备隔离 |
| 连不上 MQTT | 电脑 IP 变了 → 改固件 MQTT_BROKER 重烧；防火墙放行 1883 |
| 土壤湿度恒为 100% 或 0% | ①没接传感器但 YL69_INSTALLED=1 ②AO 接错引脚（必须 GPIO3）③探头插法（插土里，别泡水里） |
| 温度/湿度假值（1-2°C） | DHT11 没接但 DHT11_INSTALLED=1 → 设 0 重烧 |
| 串口监视器空白 | USB CDC On Boot 未开 / Serial 走 UART0；不影响 WiFi+MQTT 功能 |
| 控制风扇没反应 | ①继电器触发电平反了(LOW↔HIGH) ②继电器 VCC 没接 5V ③GND 没共地 |
| 数据在 2 个值之间跳 | 模拟器和 ESP32 同主题竞争 → 系统已升级让位机制，重启系统生效 |
